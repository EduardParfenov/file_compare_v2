## Why

В разделе 14 `AGENTS.md` агент лишён права autonomously делать `git commit` / `git push`. Это замедляет работу: после каждого согласованного изменения пользователь должен сам фиксировать коммит, создавать ветку и пушить. Нужно заменить полный запрет на правило «коммиты и пуши только с явного разрешения пользователя» — агент готовит изменения, а пользователь единолично утверждает коммит и пуш.

## What Changes

- В `AGENTS.md` раздел 14: заменить пункт 1 «Делать `git commit` или `git push` — только пользователем» на правило, что агент может подготовить изменения, но коммит, создание ветки и push выполняются только после явного разрешения пользователя на каждый шаг.
- Остальные пункты раздела 14 (создание OpenSpec-артефактов, переходы между шагами планирования) оставляются без изменений.

## Capabilities

### New Capabilities

(нет — изменение только правил взаимодействия с агентом, новая возможность не вводится)

### Modified Capabilities

(нет — требования уровня спецификации не меняются; меняется только процесс взаимодействия с агентом)

## Impact

- `AGENTS.md` — раздел 14 «Правила взаимодействия с агентом».
- `.openspec.yaml` — требуется `skip_specs: true`, так как изменение не вводит и не меняет spec-требований (чисто dokumentционный/процессуальный фикс).
