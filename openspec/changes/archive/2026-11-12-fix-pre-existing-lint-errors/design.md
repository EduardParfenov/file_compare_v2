## Context

Текущее состояние: в `.github/workflows/ci.yml` (change `ci-pipeline-completeness-review`, backlog пункт P2.11b) добавлены шаги `ruff check` и `ruff format --check`. При запуске `ruff check` без временных игноров выявляется 11 ошибок F401/F841 в трёх файлах (`services/vllm_client.py`, `tests/test_frontend_diff_mapping.py`, `tests/test_main.py`). В `ruff.toml` заведены временные `per-file-ignores` для этих файлов с пометкой, что они снимаются после очистки (см. комментарии в файле и backlog P2.11b). Ограничение: проект не конвертирует PDF в Markdown, не меняет публичное API, все правки — только удаление неиспользуемого кода.

## Goals / Non-Goals

**Goals:**
- Устранить все pre-existing lint-ошибки F401 (неиспользуемые импорты) и F841 (неиспользуемые переменные), найденные `ruff check --isolated`.
- Снять временные `per-file-ignores` из `ruff.toml`, так как они больше не нужны.
- Обеспечить прохождение `ruff check .` и `pytest` без ошибок (разблокировать слияние PR #10).
**Non-Goals:**
- Исправление ошибок форматирования (`ruff format --check`) — вне текущего объёма; пользователь явно chiesto устранить lint-ошибки (неиспользуемые импорты/переменные). Форматирование можно вынести в отдельную итерацию.
- Изменение поведения системы, публичного API, маршрутов, конфигурации.
- Добавление новых возможностей или тестов.

## Decisions

1. Исправлять только F401/F841 (неиспользуемые импорты и переменные), а не проводить всеобъемлющий рефакторинг. Обоснование: пользователь явно перечислил этот объём; остальное — отдельные задачи backlog (P2.4, P2.5 и др.).
2. Удалить все три записи `per-file-ignores` из `ruff.toml` после очистки соответствующих файлов. Обоснование: игноры помечены временными и предназначались именно для этих нарушений.
3. Форматирование (`ruff format --check`) оставить вне объёма. Обоснование: не входит в заявленный запрос; если потребуется, оформляется отдельным изменением.
4. Не вводить новые возможности и не менять спецификации поведения — изменение не затрагивает требования, поэтому `skip_specs: true`.

## Risks / Trade-offs

- [Risk] После удаления импортов/переменных может раскрыться иная ленивая проблема (например, код полагался на неявный импорт). → Mitigation: прогнать `pytest` и `ruff check` после каждой правки; при сбое уточнить у пользователя.
- [Risk] Снятие игноров из `ruff.toml` сделает линтер строже для этих файлов в будущем. → Mitigation: это целевое состояние (backlog P2.11b); новые нарушения будут ловиться CI.
- [Trade-off] Форматирование не исправляется — 6 файлов могут не пройти `ruff format --check` в CI, если этот шаг включён. → Mitigation: зафиксировано в Non-Goals; при необходимости отдельное изменение.
