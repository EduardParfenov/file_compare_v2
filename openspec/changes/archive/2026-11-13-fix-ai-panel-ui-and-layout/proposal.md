## Why

Три дефекта интерфейса мешают пользоваться приложением, и ни один из них не ловится существующими тестами:

- **Панель ИИ-аналитики не сворачивается.** `static/index.html` вызывает `toggleAiPanel()` через inline-атрибут `onclick`, а `static/app.js` подключается как ES-модуль, поэтому функция не попадает в глобальную область видимости. В браузере каждый клик по шапке панели даёт `pageerror: toggleAiPanel is not defined` (проверено в headless Chromium), и панель остаётся развёрнутой.
- **Пустой ответ ИИ-модели остаётся незамеченным.** Бэкенд корректно отдаёт «успешный, но пустой» поток (HTTP 200 без единого кадра данных), однако фронтенд не отслеживает, пришёл ли хоть один фрагмент: область вывода очищается перед запуском и остаётся пустой без пояснения.
- **Нижняя часть интерфейса срезана.** `body` не является flex-контейнером, а `main` задаёт `h-full`, поэтому при высоте окна 800 px содержимое занимает 865 px и обрезается `overflow: hidden` — кнопка «Сгенерировать ИИ-отчёт по странице» и часть области вывода ИИ недоступны (измерено: `body.scrollHeight` = 865 при `clientHeight` = 800).

Существующий браузерный тест `tests/test_frontend_upload.py` проверяет отсутствие JS-ошибок, но не выполняет клик по шапке панели — поэтому первый дефект проходит незамеченным.

## What Changes

- `static/index.html`: убрать inline-обработчик `onclick="toggleAiPanel()"` у шапки боковой панели ИИ-аналитики и дать шапке идентификатор для подписки.
- `static/app.js`: зарегистрировать переключение панели ИИ-аналитики через `addEventListener`; отслеживать, получен ли хотя бы один фрагмент ответа модели, и показывать отдельное пояснение, если успешный ответ оказался пустым.
- `static/index.html`: перестроить вертикальную раскладку — `body` становится flex-колонкой, `header` получает `shrink-0`, у `main` убирается `h-full` и добавляется `min-h-0`.
- `static/index.html` / `static/styles.css`: добавить отдельный блок пояснения о пустом ответе модели, скрываемый тем же механизмом `ui-hidden`, что и блок ошибки.
- `tests/conftest.py`: вынести дублирующийся браузерный харнесс (подъём приложения в фоновом потоке, браузер, страница, тестовые PDF) из двух тестовых файлов в общие фикстуры.
- `tests/test_frontend_upload.py`, `tests/test_frontend_ai_stream_error.py`: перейти на общие фикстуры без изменения проверок.
- `tests/test_frontend_ui_layout.py`: браузерные тесты на сворачивание панели ИИ, пояснение при пустом ответе модели и отсутствие вертикального обрезания интерфейса.

Контракт API, формат SSE-кадров и поведение бэкенда не меняются.

## Impact

Затронуты файлы: `static/index.html`, `static/app.js`, `static/styles.css`, `tests/conftest.py`, `tests/test_frontend_upload.py`, `tests/test_frontend_ai_stream_error.py`, новый файл `tests/test_frontend_ui_layout.py`.

Бэкенд, маршруты API, формат SSE-кадров и зависимости не меняются; публичный API Python не меняется. Изменение наблюдаемо для пользователя: панель ИИ начинает сворачиваться и разворачиваться, пустой ответ модели получает пояснение, нижняя часть интерфейса (кнопка отчёта по странице, область вывода ИИ) становится доступна.

Измеренное текущее состояние (headless Chromium, окно 1280×800): `body.scrollHeight` = 865 при `body.clientHeight` = 800; клик по шапке панели ИИ даёт `pageerror: toggleAiPanel is not defined`. Целевое состояние после правки раскладки проверено тем же способом: `body.scrollHeight` = 800, панель ИИ видна полностью (`aside.bottom` = 800 при высоте окна 800), при окне 1024×700 — `body.scrollHeight` = 700.

Вне объёма change'а (сознательно): геометрия diff-оверлея и модель масштаба (P0.3), lockstep-синхронизация и спейсеры (P0.4), контекст для ИИ-анализа (P0.5), валидация загрузок (P1.2), приведение кода к стилю (P2.15). Регрессионный тест на совпадение подсветки со словами на странице не добавляется: он падал бы до исправления P0.3, измеренное расхождение (148 px при ширине canvas 447 px против слоя 595 px) фиксируется как входные данные для будущего change'а по P0.3.
