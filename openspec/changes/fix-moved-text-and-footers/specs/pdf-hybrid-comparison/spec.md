## ADDED Requirements

### Requirement: Колонтилы выносятся из основного текста и сравниваются отдельно

Система SHALL выделять колонтилы — текст в нижней полосе страницы (полоса — `FOOTER_BAND = 40.0` пунктов снизу страницы) — в поле `footer_text` результата `extract_text_and_coords`: поля `pages[i]["text"]`, `pages[i]["words"]` и `full_text` (холст для diff-матчинга) SHALL не содержать колонтильного текста. Ответ `POST /api/v1/compare` SHALL включать поле `footer_diff` — diff объединённых `footer_text` обеих версий (структура `left_panel` / `right_panel` / `summary`, вычисленная `compute_diff`).

#### Scenario: Колонтильный текст распознан и исключён из основного текста

- **WHEN** PDF-документ имеет текст в нижней полосе страницы
- **THEN** поле `pages[i]["footer_text"]` содержит этот текст; поля `text`, `words` и `full_text` его не содержат

#### Scenario: Документ без колонтилов

- **WHEN** нижняя полоса страницы не содержит текста
- **THEN** `footer_text` — пустая строка; основной текст попадает в `full_text` целиком

#### Scenario: Изменения колонтилов сравниваются отдельно

- **WHEN** колонтильный текст отличается между версиями (например, номера страниц)
- **THEN** это попадает в `footer_diff`; основные панели diff-результата об этом не содержат

#### Scenario: Основной текст не содержит колонтильных строк

- **WHEN** бэкенд извлекает текст страниц с колонтилами
- **THEN** `full_text` (вход diff-match-patch) не включает текст колонтилов; колонтильных слов нет в `words`

### Requirement: Перемещённый текст — не считается изменением

Фронтенд SHALL подавлять пометки DELETE/INSERT на словах, текст которых присутствует в основном тексте (поле `text` соответствующей страницы) другой версии: маркер, присвоенный diff, считается артефактом перемещения, и слово SHALL получать операцию EQUAL.

#### Scenario: Абзац перенесён со страницы 2 на страницу 3

- **WHEN** текст абзаца в версии А находится на странице 2, в версии Б — на странице 3 (страница 3 есть в обеих версиях)
- **THEN** слова перемещённого абзаца не получают подсветку DELETE (левая панель) / INSERT (правая панель)

#### Scenario: Реальное удаление не подавляется

- **WHEN** отмеченное diff-ом слово отсутствует в основном тексте другой версии
- **THEN** пометка DELETE / INSERT остаётся и слово подсвечивается

#### Scenario: Реальная вставка не подавляется

- **WHEN** новое слово отсутствует в основном тексте другой версии
- **THEN** пометка INSERT остаётся

#### Scenario: Поведение без информации о другой версии

- **WHEN** информация об основном тексте другой версии недоступна
- **THEN** маркировка слова не меняется
