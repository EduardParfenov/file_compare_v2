# Backlog — file-compare-v2

Нерешённые задачи по результатам анализа проекта. Приоритеты: **P0** — блокеры, **P1** — высокие, **P2** — средние/низкие.

## P0 — Блокеры

- [ ] **P0.1 Конфигурация и запуск**
  - [ ] Загружать `.env` (например, `load_dotenv`) с понятным приоритетом относительно уже заданных переменных окружения; учесть, что `vllm_client` создаётся как синглтон на импорте.
  - [ ] Добавить `python-multipart` (и при необходимости dev-зависимости вроде `playwright`) в `requirements.txt` в соответствии с фактическим использованием.
  - [ ] Добавить маршрут `GET /` (redirect или `FileResponse`) на UI вместо 404 на корне.
  - [ ] Указывать путь к `static/` относительно `__file__`, чтобы запуск не зависел от CWD.
  - [ ] Не раскрывать внутренний URL vLLM в публичных ответах без необходимости (пересмотреть `/api/v1/health`).
- [ ] **P0.2 Ошибки стриминга vLLM и контракт SSE**
  - [ ] Обеспечить корректную обработку ошибок: 502 при сбое до первого чанка; при ошибке во время стрима — явный сигнал клиенту (например, `event: error` в SSE) и корректное закрытие потока.
  - [ ] Привести фронтенд к обработке ошибок стрима (не только HTTP-статус).
  - [ ] Добавить тесты на async-генератор, падающий при итерации (не только синхронный `raise` в моке).
  - [ ] Синхронизировать спецификацию `pdf-hybrid-comparison` с фактическим контрактом ошибок.
- [ ] **P0.3 Геометрия diff-overlay и canvas**
  - [ ] Согласовать масштаб/размеры `canvas` и `.diff-layer` при responsive-сжатии (`max-width`/resize): единый источник масштаба (fit-to-width или фиксированный 1:1 — зафиксировать в design).
  - [ ] Пересчитывать позиционирование боксов при изменении размера окна.
  - [ ] Проверить отсутствие искажений пропорций и «уезда» подсветки на узких экранах.
- [ ] **P0.4 Синхронизация скролла (lockstep) и спейсеры**
  - [ ] Реализовать реальную привязку к текстовым якорям (EQUAL-блокам) вместо синхронизации по номеру страницы/пропорции `scrollTop`.
  - [ ] Сделать компенсирующие спейсеры влияющими на layout (или заменить механизм) так, чтобы неизменённые фрагменты оставались выровненными при INSERT/DELETE.
  - [ ] Обновить спецификацию/приёмочные критерии и не помечать задачи выполненными без воспроизводимой проверки на многостраничных PDF с крупными вставками/удалениями.
- [ ] **P0.5 Контекст для ИИ-анализа**
  - [ ] Передавать в `/api/v1/analyze` релевантный контекст (текст, diff/summary), а не только пользовательский промпт.
  - [ ] Для отчёта по странице обеспечить сравнимый визуальный/текстовый контекст (обе версии или явно зафиксированный односторонний режим) — сейчас используется только левая страница.
  - [ ] Уточнить формат сообщений/ролей для vLLM (Qwen3-VL) и лимиты размера payload.
- [ ] **P0.6 UI: доступность панели ИИ и отображение ошибок**
  - [ ] Исправить сворачивание AI-панели (`toggleAiPanel` недоступна из inline-обработчика при модульном скрипте).
  - [ ] Унифицировать классы скрытия ошибок (`hidden` vs `ui-hidden`), чтобы ошибки анализа/отчёта были видны пользователю.
  - [ ] Устранить обрыв UX при ошибках стрима (пустой вывод без сообщения).
